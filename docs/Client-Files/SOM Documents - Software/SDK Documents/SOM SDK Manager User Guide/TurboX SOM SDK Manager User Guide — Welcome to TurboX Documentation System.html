    Introduction

    Introduction

    Thundercomm TurboX SOM SDK Manager (hereinafter referred to as "sdkmanager") is an all-in-one tool that bundles developer software and provides an end-to-end development environment setup solution for TurboX SOM SDKs.

    sdkmanager can provide you with:

    • A central location to cater to all your software development needs.
    • Quick and easy setup of your development environment.
    • Simple updates that can keep your system up-to-date with the latest releases.
    • Support for different TurboX SOM platforms.
    • The ability to compile the SDK source code.
    • The ability to flash the image to Development Kit.
    • The ability to initialize accounts and download SDK codes.
    • The ability to debug the Development Kit, such as capture of logs and ramdump. (Planning)

    Environment Setup

    System Requirement

    Category

    Requirement

    Operating system

    • SDK of software versions other than Android 12: ≥300GB

    Install Ubuntu on PC

    sdkmanager is released in the form of Docker image. Two Docker images are provided, based on Ubuntu 18.04 and Ubuntu 20.04 respectively. The Docker images have been verified on 64-bit Ubuntu Desktop 18.04, 20.04 and 22.04. Therefore, it is required to install Ubuntu Desktop 18.04, 20.04 or 22.04 on your PC and then run Docker on this system.

    Refer to the official Ubuntu tutorials: http://www.ubuntu.com/download/desktop/install-ubuntu-desktop.

    Install Docker Engine

    Install Docker Engine by running the following commands in the terminal:

    sudo apt-get update
    sudo apt-get install ca-certificates curl gnupg lsb-release
    sudo mkdir -p /etc/apt/keyrings
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
    sudo apt-get update
    sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin

    For more information, refer to the official document of Docker: https://docs.docker.com/engine/install/ubuntu.

    Install and Run sdkmanager

    We provide a script named turbox-sdkmanager-setup.sh for one-stop installation and running of sdkmanager.
    Install turbox-sdkmanager-setup.sh by running the following commands in the terminal:
    sudo apt-get install wget
    sudo wget https://sdkgit.thundercomm.com/api/v4/projects/4649/repository/files/turbox-sdkmanager-setup.sh/raw?ref=main -O /usr/bin/turbox-sdkmanager-setup.sh
    sudo chmod +x /usr/bin/turbox-sdkmanager-setup.sh
    NOTE: 
    If you have installed version V4.0.0 or earlier, you may encounter the following error during the update process:
    cp: cannot create regular file '/home/turbox//usr/bin': No such file or directory
    Solution: Please delete /usr/bin/turbox-sdkmanager-setup.sh and then re-run "Install and Run sdkmanager".
     
    turbox-sdkmanager-setup.sh user instructions
    • With initial execution of turbox-sdkmanager-setup.sh script, the latest sdkmanager will be installed and run.
    • With subsequent execution of turbox-sdkmanager-setup.sh, the installed sdkmanager will be run directly.
    • --tag specifies the version of sdkmanager. Example:
               turbox-sdkmanager-setup.sh --tag v1.0.0 Run sdkmanager of v1.0.0.
                For more information on sdkmanager versions, refer to sdkmanager Release History.
    • --os-version specifies the OS version of sdkmanager.
               turbox-sdkmanager-setup.sh --os-version 18.04 Specify the sdkmanager built based on Ubuntu 18.04.
               turbox-sdkmanager-setup.sh --os-version 20.04 Specify the sdkmanager built based on Ubuntu 20.04.
    In most cases, you need to use the sdkmanager built based on Ubuntu 18.04. For more information, refer to the Software Release Notes of each SDK.
     
    After running turbox-sdkmanager-setup.sh, you will log in to the sdkmanager environment as turbox user (password: turbox123).
    For example, run the up-to-date sdkmanager built based on Ubuntu 18.04.

    Initialize sdkmanager APP

    NOTE: This module is supported on sdkmanager version 18.04-3.0.0/20.04-1.0.0 and later versions.

    Before initializing sdkmanager app, you need to create an SDK Git access token (refer to TurboX SDK Git User Guide).
    1. Enter thesdkmanager --initcommand in the sdkmanager terminal window.
    2. Enter the SDK Git access token.
    3. Enter your Email address for SSH Key. 
    4. Press Enter to select the default SSH Key options.
    5. Set your desired git account for submitting the code.
    6. Select your region, as your SDK download speed is closely related to your choice of region.
    NOTES:
    • If you want to reinitialize the sdkmanager app,  you can execute thesdkmanager --initcommand in the terminal again.
    • When setting SSH Key, make sure that you select the default SSH Key options, otherwise it may cause errors.

    Download SDK

    NOTE: This module is supported on sdkmanager version 18.04-3.0.0/20.04-1.0.0 and later versions.

    Once initialized, sdkmanager app can read the account permissions.
    Proceed with the following steps to download the SDK.
    1. Enter thesdkmanager --sdk_downloadcommand in the sdkmanger terminal window.
    2. Select the product name of your device by entering the corresponding number as prompted.
    3. Select the branch name of the SDK by entering the corresponding number as prompted.
    4. Select the version name of the SDK by entering the corresponding number as prompted.
    5. Select the SDK download path.
    6. Wait for a while and then the SDK will be downloaded to the specified path.

    NOTES:
    • The sdkmanager app has permission control restrictions. If the SDK you need to download is not found in the third-level directory, it means that  you do not have permission for the SDK. Please contact Thundercomm to request relevant permission.
    • Do not delete /home/turbox/workspace/local_mirror as the local mirror of code repository will be saved in this directory. It may take long to download the local mirror for the first time. To greatly improve the download efficiency, you can use the code in the local_mirror. To download the SDK to another PC, you can copy the local_mirror directory to the same path, which can speed up SDK download process.

    Download Image

    NOTE: This module is supported on sdkmanager version v3.0.0 and later versions.
    Once initialized, sdkmanager app can read the account permissions.
    Proceed with the following steps to download images released by Thundercomm.
    1. Enter thesdkmanager --image_downloadcommand in the sdkmanger terminal window.
    2. Select the product name of your device by entering the corresponding number as prompted.
    3. Select the release name of the image by entering the corresponding number as prompted.
    4. Select the image by entering the corresponding number as prompted.
    5. Select the image download path.
    6. Wait for a while and then the image will be downloaded to the specified path.

    NOTE: The sdkmanager app has permission control restrictions. If your desired image is not found in the third-level directory, it indicates that you do not have permission for this image. Please contact Thundercomm to request relevant permission.

    Flash images to board

    Tflash (TurboX Flash), an image burning tool developed by Thundercomm, can be used to flash FlatBuild onto Thundercomm SOM modules. For detailed information, please refer to TurboX Flash User Guide.

    Uninstall TurboX sdkmanager

    sdkmanager is based on Docker Container. You can uninstall it by proceedding with the following steps.

    1. Remove the container.

         a. Check the container ID that you want to remove.

      sudo docker container ps -a         

         b. Stop the container.

             sudo docker container stop e785ff02d2a6 #Replace e785ff02d2a6 with your container ID

         c. Remove the container.

              sudo docker container rm e785ff02d2a6    #Replace e785ff02d2a6 with your container ID

    2. Remove the Docker Image.

         a. Check the image ID that you want to remove.

             sudo docker images         

         b. Remove the Docker Image.

             sudo docker rmi 1513028ad3e2                       #Change 1513028ad3e2 to your IMAGE ID

    Troubleshoot

    Problem

    Solution
    Unable to connect the device via running adb in turbox-sdkmanager environment.
    On your host machine, stop the adb server by runing the following command in the termimal:
     $ sudo adb kill-server
